<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Server -> All Clients | Socket.IO broadcast sends order book data to every connected browser — must not leak private order fields (userId, orderId) |
| DB -> Broadcast Transform | Raw Order objects from getOrderBook() cross into the broadcast payload — transformation must strip private fields |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Information Disclosure | server.ts broadcast loop | mitigate | Transform Order[] to {price, quantity}[] via safeBook() helper before io.emit('orderbook') — never broadcast raw Order objects. Test in socket-broadcast.test.ts asserts no userId in payload. |
| T-02-02 | Denial of Service | Socket.IO server | accept | Friends-only app with <10 concurrent users. No rate limiting needed. socket.io has built-in backpressure. |
| T-02-03 | Spoofing | Socket.IO connection | accept | Phase 2 broadcasts public market data only — no authentication needed for read-only price/book data. User-specific actions remain behind JWT-protected REST API. |
</threat_model>

**Step 1: Create `coinxi/src/components/OrderBookTable.tsx`** (per D-13, D-14, UI-05).

This component receives bids, asks, bidsDiff, and asksDiff from the parent (trade page calls `useOrderBook`). It renders two sides (bids/asks) with Framer Motion animations.

Key implementation details:
- Use `AnimatePresence mode="popLayout"` wrapping the rows (per RESEARCH.md Pattern 6)
- Each row is a `motion.div` (not `motion.tr` — avoid table element animation issues) with `key={level.price}` (D-14: price is the stable row key)
- New levels: `initial={{ x: side === 'bid' ? -10 : 10, opacity: 0 }}`, `animate={{ x: 0, opacity: 1 }}` (per D-13)
- Removed levels: `exit={{ opacity: 0, height: 0, overflow: 'hidden' }}` (per D-13)
- Updated quantity flash: use `useEffect` watching `status === 'updated'` to trigger a background color flash. Flash color: `#00d4ff` (cyan) for quantity increase, `var(--color-red)` for decrease (per D-13). Compare current quantity with prevQuantityRef to determine increase/decrease. Flash fades over ~400ms using CSS transition or Framer Motion `animate`.
- Use `getRowStatus(level.price, diff)` to classify each row
- Props: `{ bids: BookLevel[], asks: BookLevel[], bidsDiff: DiffResult, asksDiff: DiffResult }`
- Display: two-column layout. Left column = Asks (sell, red prices), Right column = Bids (buy, green prices). 
- Each row shows: price (colored) and quantity (muted).
- Max 20 rows per side (data already sliced server-side, but guard with `.slice(0, 20)`)
- Add `'use client'` directive
- Import `AnimatePresence, motion` from `'framer-motion'` (same import path as PriceTicker.tsx)
- Spring transition: `{ type: 'spring', stiffness: 400, damping: 30 }` (matching PriceTicker pattern)

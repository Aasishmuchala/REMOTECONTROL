Create `coinxi/src/app/api/orders/all/route.ts` with a single `GET` export.

Per D-06: This is a new route separate from `/api/orders` (which stays pair-scoped for the trade page). Per D-05: Returns all user orders across all pairs. Per D-07: Filled/cancelled orders limited to last 7 days at the DB query level; pending/partial always returned.

**CRITICAL (D-07 DoS protection):** The 7-day limit MUST be enforced at the DB query level using `gte(orders.createdAt, sevenDaysAgo)`, NOT via JS filtering after fetching all rows. This prevents unbounded result sets from hitting the application.

The route must:

1. **Auth check:** `getAuthUser(req)` -> 401 if null.

2. **Parse status param:** `const status = new URL(req.url).searchParams.get('status')`.

3. **Validate status:** If status is provided, validate against whitelist `['open', 'partial', 'filled', 'cancelled']`. If invalid, return `errorResponse('Invalid status. Must be one of: open, partial, filled, cancelled', 400)`. If status is null/absent, fetch all statuses.

4. **Compute date boundary:** `const sevenDaysAgo = new Date(Date.now() - 7 * 24 * 60 * 60 * 1000).toISOString()`

5. **Execute two DB queries and merge results (DB-level filtering per D-07):**

```typescript
import { eq, and, gte, inArray, or } from 'drizzle-orm'
import { orders } from '@/db/schema'

// Query 1: Open/partial orders — no date filter, always returned
const pendingStatuses = ['open', 'partial'] as const
const historicalStatuses = ['filled', 'cancelled'] as const

let pendingOrders: typeof allOrders = []
let historicalOrders: typeof allOrders = []

if (!status || pendingStatuses.includes(status as any)) {
  const pendingFilter = status
    ? and(eq(orders.userId, user.userId), eq(orders.status, status))
    : and(eq(orders.userId, user.userId), inArray(orders.status, ['open', 'partial']))
  pendingOrders = await db.select().from(orders).where(pendingFilter)
}

// Query 2: Filled/cancelled orders — with 7-day date filter (D-07 DoS protection)
if (!status || historicalStatuses.includes(status as any)) {
  const historicalFilter = status
    ? and(eq(orders.userId, user.userId), eq(orders.status, status), gte(orders.createdAt, sevenDaysAgo))
    : and(eq(orders.userId, user.userId), inArray(orders.status, ['filled', 'cancelled']), gte(orders.createdAt, sevenDaysAgo))
  historicalOrders = await db.select().from(orders).where(historicalFilter)
}

const allOrders = [...pendingOrders, ...historicalOrders]
```

6. **Sort by createdAt DESC** (newest first for display): `allOrders.sort((a, b) => a.createdAt > b.createdAt ? -1 : 1)`

7. **Return:** `jsonResponse(allOrders)`.

Imports:
```typescript
import { NextRequest } from 'next/server'

```

Security: Always filter by `eq(orders.userId, user.userId)` in EVERY query — never expose other users' orders (IDOR mitigation T-04-02). The `gte(orders.createdAt, sevenDaysAgo)` is applied at query level for filled/cancelled, ensuring the DB never returns unbounded historical data.

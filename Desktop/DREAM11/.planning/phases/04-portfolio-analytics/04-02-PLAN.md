Create `coinxi/src/app/api/orders/all/route.ts` with a single `GET` export.

Per D-06: This is a new route separate from `/api/orders` (which stays pair-scoped for the trade page). Per D-05: Returns all user orders across all pairs. Per D-07: Filled/cancelled orders limited to last 7 days; pending/partial always returned.

The route must:

1. **Auth check:** `getAuthUser(req)` -> 401 if null.

2. **Parse status param:** `const status = new URL(req.url).searchParams.get('status')`.

3. **Validate status:** If status is provided, validate against whitelist `['open', 'partial', 'filled', 'cancelled']`. If invalid, return `errorResponse('Invalid status. Must be one of: open, partial, filled, cancelled', 400)`. If status is null/absent, return all statuses (no filter).

4. **Fetch orders:** Use Drizzle to query the orders table filtered by `eq(orders.userId, user.userId)`. Do NOT use `inArray` initially — instead fetch all user orders and filter in JS (same pattern as `matching-engine.ts` line 280, Pitfall 4 from RESEARCH.md). This avoids import path uncertainty with `inArray`.

```typescript
import { eq } from 'drizzle-orm'
import { orders } from '@/db/schema'

const allUserOrders = await db.select().from(orders).where(eq(orders.userId, user.userId))
```

5. **Apply status filter in JS:**
```typescript
const VALID_STATUSES = ['open', 'partial', 'filled', 'cancelled'] as const
type OrderStatus = typeof VALID_STATUSES[number]

let filtered = allUserOrders as Array<typeof allUserOrders[number]>
if (status) {
  filtered = filtered.filter(o => o.status === status)
}
```

6. **Apply 7-day limit for filled/cancelled (D-07):**
```typescript
const sevenDaysAgo = new Date(Date.now() - 7 * 24 * 60 * 60 * 1000).toISOString()
filtered = filtered.filter(o => {
  if (o.status === 'open' || o.status === 'partial') return true
  // For filled/cancelled: only include if within last 7 days
  return o.createdAt >= sevenDaysAgo
})
```

7. **Sort by createdAt DESC** (newest first for display): `filtered.sort((a, b) => a.createdAt > b.createdAt ? -1 : 1)`

8. **Return:** `jsonResponse(filtered)`.

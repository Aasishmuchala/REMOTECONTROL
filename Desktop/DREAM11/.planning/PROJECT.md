# CoinXI

## What This Is

A crypto-fiat exchange platform for friends to trade cryptocurrency among themselves using credits (not real money). The platform simulates a professional exchange experience — deposit credits, trade crypto pairs, track portfolios — with an Awwwards-caliber UI that showcases premium design quality.

## Core Value

A beautifully designed, fully functional crypto exchange that demonstrates world-class product craft — every pixel, every interaction, every flow is polished. Credits-only means zero financial risk while enabling complete exchange functionality.

## Vision

Cinematic luxury meets fintech precision. Think dark glass surfaces, subtle glows, fluid animations, and typographic confidence. Every screen should feel like it belongs on awwwards.com's best of the day.

## Requirements

### Active

- [ ] Friends-only crypto-fiat exchange with credits system
- [ ] Awwwards-caliber UI design inspired by top fintech/exchange apps
- [ ] Full trading functionality: order book, market/limit orders, trade history
- [ ] User wallet system with crypto deposits/withdrawals (credits)
- [ ] KYC flow (simulated for demo purposes)
- [ ] Portfolio dashboard with P&L tracking
- [ ] Real-time market data display
- [ ] Mobile-responsive design

### Out of Scope

- Real money / actual financial transactions
- Real regulatory compliance (simulated KYC only)
- Fiat on/off ramps
- External exchange integrations
- Institutional trading terminal

## Design Direction

### Visual Style
- **Aesthetic:** Dark cinematic luxury — glassmorphism, subtle gradients, refined shadows
- **Inspiration:** Binance, Bybit, Robinhood (dark mode), Stripe's polish
- **Reference:** awwrds.com — daily favorites, fintech category

### Color Palette
- **Background:** Deep blacks and charcoals (#0a0a0f, #12121a)
- **Surface:** Elevated dark glass (#1a1a24, rgba(255,255,255,0.03))
- **Primary accent:** Electric cyan (#00d4ff) for CTAs and highlights
- **Secondary:** Muted purple (#8b5cf6) for secondary actions
- **Success:** Emerald green (#10b981)
- **Danger:** Rose red (#f43f5e)
- **Text:** White (#ffffff) primary, slate (#94a3b8) secondary

### Typography
- **Display:** Space Grotesk or Inter (700) — bold, confident headlines
- **Body:** Inter (400/500) — clean, readable
- **Mono:** JetBrains Mono — for prices, numbers, code

### Motion Philosophy
- Smooth 300-400ms transitions for state changes
- Micro-interactions on every interactive element (buttons, cards, inputs)
- Staggered list animations for trading pairs, order book
- Number animations for price changes (smooth counting)
- Page transitions: subtle fade + slide

## Constraints

- **Tech stack:** React + TypeScript (web), Tailwind CSS, Framer Motion for animations
- **No real money:** Credits system only — internal balance tracking
- **Friends access:** Invite-only or simple sign-up
- **UI quality:** Must match or exceed top fintech apps on awwrds.com

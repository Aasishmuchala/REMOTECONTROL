    Create the 5-stage pipeline orchestrator in apps/backend/src/pipeline/analysis-router.ts:

    1. Export `runAnalysis(url: string): Promise<AnalysisResult>`
    2. Stage 1 - Capture (parallel internally):
       - capturePage(url) -> {screenshot, dom, viewport}
       - Time budget: 2s max
    3. Stage 2 - Analysis (parallel):
       - generateHeatmap(screenshot) -> heatmap
       - runAccessibilityCheck(dom) -> accessibility
       - computeCognitiveLoad(dom, screenshot) -> cognitiveLoad
       - analyzeVisualHierarchy(dom, heatmap) -> hierarchy
       - Time budget: 3s max
    4. Stage 3 - Scoring:
       - computeNeuroScore(components) -> neuroScore
       - Time budget: 1s max
    5. Stage 4 - DesignMind (placeholder):
       - For MVP: generate basic critique from scores
       - Full DesignMind in Phase 2
       - Return: {critique: string, recommendations: BasicRecommendation[]}
       - Time budget: 2s max
    6. Stage 5 - Render (frontend handles):
       - Return structured data for dashboard
       - Store in DB for history

    7. Error handling (per STATE.md - never block on failure):
       - Wrap each stage in try/catch
       - If any model fails: return partial results with errors array
       - If critical (capture fails): throw with specific error
       - Track: {success: true/false, completedStages: string[], errors: Error[]}

    8. Store Analysis in Prisma:

       ```prisma
         scrollDepth  Float?
         hierarchy    Float?
         accessibility Float?
         cognitiveLoad Float?
         critique     String?
         recommendations Json?

         completedAt  DateTime?
         createdAt    DateTime @default(now())
       }
       ```
